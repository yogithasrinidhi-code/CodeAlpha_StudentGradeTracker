# Student Grade Tracker

## Project Description

Student Grade Tracker is a simple console-based Java application developed as part of the CodeAlpha Java Programming Internship – Task 1.

The application allows users to enter and manage student marks, calculate average marks, find the highest and lowest scores, and generate a summary report.

## Features

- Add student names and marks.
- View all student records.
- Calculate the average marks of all students.
- Find the student with the highest marks.
- Find the student with the lowest marks.
- Generate a summary report.
- Assign grades based on marks.
- Validate student marks (0–100).
- Simple menu-driven console interface.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner class
- VS Code

## How to Run the Project

### Step 1: Install Java

Make sure Java JDK is installed on your computer.

Check the installation using:

```bash
java -version
javac -version
```

### Step 2: Open the Project

Open the `StudentGradeTracker` folder in VS Code.

### Step 3: Compile the Java Files

Open the VS Code terminal and execute:

```bash
javac Main.java Student.java GradeManager.java
```

### Step 4: Run the Application

Execute:

```bash
java Main
```

### Step 5: Use the Application

Choose an option from the menu:

1. Add Student
2. View All Students
3. Calculate Average
4. Show Highest Marks
5. Show Lowest Marks
6. Generate Summary Report
7. Exit
